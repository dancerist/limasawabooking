LimasawaBooking Figma Assets

This folder contains PNG mockups of the LimasawaBooking design.
You can import these into Figma as references or place them in frames to create your Figma project.

Files included:
- mockup_1.png : High detail homepage mockup
- mockup_2.png : High resolution homepage and category mockup

Instructions:
1. Open Figma.
2. Create a new project or file.
3. Drag & drop the PNG assets into Figma.
4. Use these as references to create editable frames, layers, and components.
5. Build your Figma project around these assets, adding text layers, buttons, and components for full functionality.
